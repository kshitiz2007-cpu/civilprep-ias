# CivilPrep IAS — Rose Atelier Design System

## Approved visual direction

Rose Atelier is the primary visual identity for the web application. It replaces the previous warm-cream / terracotta visual constitution.

### Palette
- Rose canvas: #FFF8F7
- Porcelain surface: #FFFFFF / rgba(255,255,255,.82)
- Rose-magenta primary: #C83E7D
- Deep berry: #A92B69
- Blush: #F8E5ED
- Champagne gold: #BD9258
- Plum ink: #38202D
- Muted mauve: #876F7D
- Sage: #6D8B75, reserved for positive/progress states

### Typography
- Display and editorial headings: Instrument Serif.
- Product UI and body: DM Sans / Manrope.
- Hindi: Noto Sans Devanagari.
- Technical metadata: JetBrains Mono.
- Use expressive serif display typography for major headings; keep dense study content and controls highly legible.

### Surfaces and depth
- Porcelain glass surfaces with visible rose-tinted borders.
- Soft layered shadows, subtle blur and restrained reflective highlights.
- Rounded corners: 11px small, 16px medium, 22px large, 28px hero.
- Use gradients as accents and depth cues, not as a replacement for hierarchy.

### Motion and interaction
- Fast feedback: 140ms.
- Standard transitions: 220ms.
- Page transitions and staged reveals: 320–550ms.
- Use motion for intentional focus, drag-to-confirm and spatial navigation.
- Respect reduced-motion preferences, touch input and keyboard access.

### Component language
- Magic Bento for capability and feature discovery.
- Gradient Text for editorial emphasis.
- Circular Carousel for subject exploration.
- Scroll Stack for sequential learning narratives.
- Slide Commit for deliberate completion actions.
- Hugeicons is the brand/icon foundation; Lucide remains acceptable for legacy route compatibility.

### Responsive rules
- Mobile-first interaction and content hierarchy.
- Avoid horizontal overflow; convert multi-column compositions into readable single-column layouts.
- Reduce decorative motion on touch and for reduced-motion preferences.
- Keep all essential actions reachable without precision gestures.
