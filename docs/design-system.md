# CivilPrep IAS — Design System v1

## Locked visual identity

This document records the user's approved app-wide visual reference.

### Colour tokens

| Token | Value | Use |
|---|---|---|
| Canvas | #F7F2E9 | Main warm background |
| Surface | #FFFDF8 | Primary panels |
| Surface warm | #F4E9D9 | Secondary cards |
| Terracotta | #C95724 | Primary actions |
| Orange | #E87524 | Active states and emphasis |
| Sage | #A7B99A | Soft supporting surfaces |
| Forest | #2F7D32 | Progress and positive status |
| Indigo | #77738C | Restrained secondary accent |
| Ink | #242522 | Primary text |
| Muted ink | #68675F | Secondary text |
| Border | #E4D8C8 | Dividers and outlines |

### Typography

- Editorial headings: Newsreader / Georgia fallback.
- UI and body: Plus Jakarta Sans / system sans fallback.
- Hindi: Noto Sans Devanagari / system sans fallback.
- Use editorial serif for page and panel titles; use sans-serif for controls, metadata and dense study content.

### Shape and depth

- Small radius: 10px
- Medium radius: 16px
- Large radius: 22px
- Hero radius: 26px
- Soft shadows only; avoid heavy glassmorphism.
- Borders should remain visible on cream backgrounds.

### Interaction

- Fast feedback: 140ms
- Standard transitions: 220ms
- Page transitions: 320ms
- Respect reduced-motion preferences.
- Provide visible keyboard focus and accessible contrast.

### Non-negotiables

- Same design language on every module and platform.
- No 3D, clay, WebGL, floating-island or camera-like environments.
- No unrelated dark-purple/neon theme.
- Illustrations are 2D and editorial.
- Mobile layouts adapt structure without changing brand identity.
